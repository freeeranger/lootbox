## What's Working

1. **Safety is visible at decision boundaries.** First import, rename, forget, purge, backup restore, cache clearing, grouping, and Godot export consistently distinguish metadata or copied files from untouched source packs.

2. **Godot export is now a signature flow.** Its preflight and completion sequence expresses Lootbox's dependency-aware, non-destructive value better than any generic asset browser could.

3. **Expert efficiency stays calm.** Persisted geometry and view state, whole-result selection, shortcuts, selection review, accessible audio seeking, natural sorting, drag-out, and bulk tooling serve large libraries without turning the interface theatrical.

## Priority Issues

### [P1] Whole-result metadata edits can lose confirmation and recovery

- **Why it matters:** Select-all can include unloaded results. Tags and collection changes still target every selected ID, but prior-state calculation is skipped when the full selection is not cached, so completion notices and Undo can disappear. Classification has the same limitation for mixed unloaded state.
- **Fix:** Resolve mutation deltas in the backend or fetch lightweight metadata for every selected ID. Return affected IDs and prior values for every bulk mutation, always announce completion, always offer Undo, and apply the high-impact confirmation threshold whenever inverse state is unavailable.
- **Suggested command:** `$impeccable harden`

### [P1] Keyboard selection is not modeled as an accessible asset browser

- **Why it matters:** Arrow keys change application selection without moving focus or exposing an active descendant. The visually simulated grid/list has no collection semantics, and result refresh is not announced with `aria-busy`. A screen reader can remain on an unrelated control while selection changes invisibly.
- **Fix:** Implement a labelled grid/listbox with roving focus or `aria-activedescendant`; announce the active asset name, position, and selected count; add row/gridcell relationships and `aria-busy` during result refresh.
- **Suggested command:** `$impeccable audit`

### [P1] Same-named Godot projects are hard to distinguish on the primary path

- **Why it matters:** The toolbar export menu lists only project names. Preflight again emphasizes only the name while the root path is hover-only. Two projects sharing a folder name can lead to a confident export into the wrong target.
- **Fix:** Route toolbar export through the richer project picker or show name plus truncated root path in the dropdown. Make the root path visibly persistent in preflight and completion.
- **Suggested command:** `$impeccable clarify`

### [P2] Review Selection cannot correct the selection it reveals

- **Why it matters:** The dialog can expose an accidental item but only offers Done. The user must close it, locate that asset in a virtualized result set, and toggle it manually.
- **Fix:** Add a remove control or checkbox per row, plus Clear selection and Remove missing. Preserve the active item and optionally add selection-only search for very large sets.
- **Suggested command:** `$impeccable layout`

### [P2] Recoverable thumbnail failures can become global workspace alarms

- **Why it matters:** Model-card generation already degrades to a safe icon, yet malformed models can still invoke the global assertive error toast. Browsing a messy pack can repeatedly interrupt the user and screen reader for a non-blocking failure.
- **Fix:** Keep card failures inline, log each unique failure once, and reserve the global alert for a selected inspector preview or task-blocking action. Offer a quiet broken-preview badge with Regenerate preview or Open diagnostics.
- **Suggested command:** `$impeccable harden`

## Persona Red Flags

**Alex—power user:** Whole-result edits can finish without Undo when some selected assets are unloaded. Review Selection cannot deselect mistakes. Unbounded project, pack, and collection lists lack quick filtering or recent-item affordances. A run of malformed models can still delay serialized thumbnail generation.

**Sam—accessibility-dependent:** Inspector buttons, audio seeking, resizers, and live progress are much improved, but arrow navigation changes selection without moving or announcing focus. The result surface lacks grid/listbox semantics and `aria-busy`. Repeated assertive thumbnail failures can overwhelm speech output. Live 200% zoom validation was unavailable.

**Mira—indie technical artist:** Export inventory is now excellent, but same-named Godot destinations are ambiguous, unloaded bulk edits may lack Undo, and selection review cannot remove a mistaken source file before a shared edit.

## Minor Observations

- Active-filter chips use full-pill radii, slightly softer than the design system's ordinary 5px chip language.
- The active-filter `aria-label` sits on a generic `div` rather than a group or landmark role.
- The Godot `Review export` recovery clears the toast but otherwise performs no visible action because the dialog is already open.
- Maintenance actions do not consistently disable controls or show in-place busy state.
- The input context menu hard-codes Ctrl labels and globally disables spellcheck/autocorrect, including human-entered collection names and tags.
- First-use, empty-inspector, export, and local-safety copy are now concise and effective.
