## 6. Recommended Polish Items

1. **[P1] Model Card Subtle Pedestal Gradient**:
   * Add a faint radial/isometric pedestal backdrop behind unrendered 3D wireframe cards so they feel distinct from empty states.
2. **[P2] Middle Truncation on Card Names**:
   * For long filenames (e.g. `space_corridor_straight.glb`), use middle truncation (`space_...straight.glb`) or show tooltip on hover so file stems remain legible.
3. **[P3] Dynamic Filter Pill Counters in Scoped Views**:
   * When filtered to a specific pack or search query, update the top type chips to reflect matching counts within that scope.
